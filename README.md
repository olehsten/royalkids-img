# Royal Kids — фото товарів

Публічне сховище фотографій товарів інтернет-магазину Royal Kids.

## Структура

```
<артикул>/1.jpg
<артикул>/2.jpg
...
```

- Одна папка на один артикул, назва папки = артикул.
- Фото нумеруються з 1; `1.jpg` — головне фото.
- Розширення в нижньому регістрі (`.jpg`, `.png`, `.webp`).

## Пряме посилання на фото

```
https://raw.githubusercontent.com/olehsten/royalkids-img/main/<артикул>/<номер>.jpg
```
