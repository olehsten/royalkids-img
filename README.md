# Royal Kids — фото товарів

Публічне сховище фотографій товарів інтернет-магазину Royal Kids.

## Назви файлів

```
<артикул>_<номер>.<розширення>
```

Наприклад: `60585017_1.jpg`, `60585017_2.jpg`, `60585017_3.png`.

- Номер — порядок фото на сайті, `_1` — головне фото.
- Розширення в нижньому регістрі (`.jpg`, `.png`, `.webp`).

## Пряме посилання на фото

```
https://raw.githubusercontent.com/olehsten/royalkids-img/main/<артикул>_<номер>.jpg
```
